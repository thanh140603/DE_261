\section{Tóm tắt API}
\label{app:api}

Tất cả endpoint có tiền tố \code{/api}. Tài liệu OpenAPI đầy đủ ở \code{http://localhost:8000/docs}. Hợp đồng chi tiết ở \code{docs/api.md}. API staff dùng cookie phiên kèm \code{X-Staff-Role} hoặc Bearer token đã khai báo. Phiên thiếu hay hết hạn trả 401. Sai vai trò, sai origin khi ghi bằng cookie hoặc ngoài phạm vi trả 403. Dữ liệu không có trả 404, truy vấn sai trả 422, vượt giới hạn thử mật khẩu trả 429 và kho chưa sẵn sàng trả 503.
