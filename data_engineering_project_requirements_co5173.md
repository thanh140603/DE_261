## 1. Objectives
The Project aims at the knowledge and skills expected in course learning outcomes. It helps learners self-study and work in groups on data engineering-related topics, enabling them to develop an application that reflects the effectiveness of data engineering results and supports improving presentation skills.

## 2. Detailed Project Description

### 2.1. Application Domain
* Each group works on **one unique application domain** within the scope of the course (e.g., education, healthcare, manufacturing, marketing, e-commerce, tourism industry, science, transportation, supply chain management, entertainment, etc.).
* **Key Tasks:**
  1. Identify the potential **key user groups** that the group would like to support.
  2. Determine the **business requirements** that need data prepared by data engineering (related to data analysis, data science, data mining, business intelligence systems, decision support systems, etc.).

### 2.2. Topic: Build a system where your data engineering solution is proved successful (in a specific application domain)
The topic requires learners to perform data engineering so that the resulting data can be utilized specifically for users in the chosen application domain. 

#### Three Main Parts of the Product:
1. **(i) Business and related data** in an application domain.
2. **(ii) Data engineering** for the business requirements.
3. **(iii) Application development** to bring the results to the real world.

#### Technology Choices (Focus on Data Management and Processing):
Each group needs to clarify and work with several technologies selected for data management and processing:
* **a. Data management:** Redshift, Hive, Synapse Analytics, Cassandra, BigQuery (BigLake), CouchBase, Databricks, Neo4J, RavenDB, Dynamo, Oracle data lakehouse, ...
* **b. Data processing:** Flink, Spark Streaming, Hadoop Map-Reduce, Storm, Kafka Stream, ...

#### Business Requirements & Benchmarking Rules:
* **Minimum Business Requirements:** At least $2 \times n$ business requirements must be defined to utilize the data from data engineering, where $n$ is the number of group members.
* The business requirements must show support for the business objectives of the enterprise in the uniquely selected application domain.
* Provide the **rationales** behind the data engineering's support for those requirements and **evaluate** the selected technologies in the solution for the system.
* **Alternative solutions** might be considered for benchmarking the selected technologies from different perspectives, especially in the Big Data context.

#### Specific Requirements for the Project (`ii. Project`):
* Introduce the context of the project topic.
* Introduce stakeholders (especially users), along with business requirements and data usage needs, in order to shape a data-driven application for the application domain of each group.
* Present the expected data sources and data characteristics that should be considered when implementing data engineering.
* Present the data engineering solution and introduce **at least one alternative solution** (for comparison).
* Present the technology for data management, the technology for data processing, and approaches to leveraging these technologies for the application.
* Develop the application for the project topic.
* Evaluate the data engineering solution and data-driven application based on the following criteria:
  * **Data correctness** after data engineering is performed.
  * **Performance** of the data engineering solution.
  * **Effectiveness** of supporting data exploitation through the application.
* Conclusions about the project.

### 2.3. Group Change Policy
* **Group changes:** Members of different groups may switch groups after the announcement, following discussion with the instructor. The condition for any change is mutual agreement among members of both original and new groups.

## 3. Project Assessment & Deliverables

> **Note:** All submitted files for assessment need to be named with your **group ID**.

### 3.1. Submissions & Weighting (Total: 35% of Course Score)
* **Due Date:** The end of our course.
* **Required Deliverables** *(All items below are mandatory for scoring the Project part)*:
  1. **Final Technical Report (PDF):** `10%` of the total score.
  2. **Presentation File (PDF):** `5%` of the total score. Needs to show the data engineering solution proposed by each group and the application that demonstrates the effectiveness of this solution in a specific application domain.
  3. **Video (`mp4` or `webm` format):** `5%` of the total score. Completed along with a presentation and application demonstration in **20–30 minutes**.
  4. **Product (Proof of Application Development):** `15%` of the total score. Showing a demonstration of the resulting application that can be executed and evaluated.
