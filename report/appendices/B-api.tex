\chapter{Tóm tắt API}
\label{app:api}

Mọi endpoint có tiền tố \code{/api}; tài liệu OpenAPI ở \code{http://localhost:8000/docs} mô tả hợp đồng chi tiết. Endpoint phân tích yêu cầu token Bearer: thiếu hoặc sai token trả 401, sai vai trò hoặc ngoài phạm vi trả 403, không có dữ liệu trả 404, truy vấn sai trả 422, kho chưa sẵn sàng trả 503.
