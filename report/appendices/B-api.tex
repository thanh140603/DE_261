\chapter{Tóm tắt API}
\label{app:api}

Mọi endpoint có tiền tố \code{/api}; tài liệu OpenAPI ở \code{http://localhost:8000/docs} mô tả hợp đồng chi tiết. Endpoint phân tích yêu cầu xác thực: trình duyệt đăng nhập bằng tài khoản nhân sự qua \code{/auth/staff/{role}/session} rồi gửi cookie phiên kèm header \code{X-Staff-Role}, còn script gửi token Bearer đã khai báo trong \code{EDU_BR45_AUTH}. Thiếu hoặc sai thông tin xác thực trả 401, sai vai trò hoặc ngoài phạm vi trả 403, không có dữ liệu trả 404, truy vấn sai trả 422, kho chưa sẵn sàng trả 503.
