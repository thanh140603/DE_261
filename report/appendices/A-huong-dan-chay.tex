\label{app:run}

\section{Yêu cầu}

Docker (khuyến nghị 8 GB RAM cho VM), Python 3.11 trở lên, Node.js 20 trở lên. Postgres của dự án mặc định ở cổng 5433 để tránh xung đột với các dự án khác.

\section{Đo alternative solutions}

Các benchmark alternative dùng file 5 GiB trong
\code{benchmarks/alternatives/data/} (gitignored). Chạy trên các tiền tố
1M/5M/10M dòng:

\begin{lstlisting}[language=bash]
# OLAP: PostgreSQL vs ClickHouse (profile bench-olap)
docker compose -f docker-compose.yml -f docker-compose.bench.yml \
  --profile bench-olap up -d bench-clickhouse
.venv/bin/python -m benchmarks.alternatives.olap.load_postgres \
  benchmarks/alternatives/data/org-facts-1m.csv
.venv/bin/python -m benchmarks.alternatives.olap.load_clickhouse \
  benchmarks/alternatives/data/org-facts-1m.csv
.venv/bin/python -m benchmarks.alternatives.olap.query_olap \
  --engine both --repeat 3 --label 1m

# Feature store: Redis bị giới hạn 512 MiB vs PostgreSQL disk
docker compose -f docker-compose.yml -f docker-compose.bench.yml \
  --profile bench-kv up -d bench-redis
.venv/bin/python -m benchmarks.alternatives.feature_store.load_redis \
  benchmarks/alternatives/data/features-1m.jsonl
.venv/bin/python -m benchmarks.alternatives.feature_store.load_postgres \
  benchmarks/alternatives/data/features-1m.jsonl
.venv/bin/python -m benchmarks.alternatives.feature_store.workload \
  --rows 1000000 --ops 10000 --label 1m
\end{lstlisting}

Kết quả chi tiết: \code{benchmarks/alternatives/results/}.
